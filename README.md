# Alpha Comix — منصة المانهوا والروايات العربية

منصة عربية احترافية لقراءة المانهوا والمانجا والروايات.

## 🌐 الموقع
https://comixalpha.dpdns.org

## 🛠️ التقنيات
- Supabase (قاعدة بيانات + مصادقة + تخزين)
- GitHub Pages (استضافة)
- GitHub Actions (بناء تلقائي)
- Chart.js (رسوم بيانية في لوحة الإدارة)

## 📁 هيكل المشروع
- `index.html` — الواجهة
- `app.js` — المنطق
- `styles.css` — التصميم
- `config.js` — إعدادات Supabase
- `scripts/build.js` — سكريبت توليد صفحات SEO
- `supabase/schema.sql` — قاعدة البيانات
- `.github/workflows/build.yml` — البناء التلقائي

## 🚀 النشر
كل ما عليك إضافة عملاً في Supabase، والبناء يعمل تلقائياً كل 6 ساعات.
